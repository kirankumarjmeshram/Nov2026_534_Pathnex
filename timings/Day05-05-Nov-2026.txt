Git

Today I learn about git

Key concepts in Git
 - Repository
 - commit
 - branch
 - merge
 - clone
 - push
 - pull

 Basic Git Commands
    1. Git config
        git config --global user.name "user_name"
        git config --global user.email "user_email"

    2. git init (initialize a new git repo)
        git init
    3. git clone <repo_url>
    4. git status
    5. git add <file_name>
       git add .
    6. git commit -m "commit message"
    7. git log
    8. git diff
    
Working with branches
    1. git branch 
       git branch <branch_name> || git switch <branch_name>
    2. git checkout <branch_name>
       git checkout -b <branch_name>
    3. git merge <branch_name>

Working With remote repositories
    1. git remote add <repo_url>
    2. git push origin <branch_name>
    3. git pull origin <branch_name>

Common Workflow in git
    1. Start project
        - Initialize the repo or clone existing one
            - git init
    2. Make changes 
        - modify or add files
    3. Track changes
        - stage file and commit them
        - git add <file_name>
        - git commit -m "message"
    4. Collaborate
        - push and pull changes to/from the remote repository
    5. Branching and merging

Git Best Practices
    - commit often, but with meaning
    - write clear commit message
    - pull often/regularly
    - push early and often

Git Interview Questons
    1. Rebase vs Merge
    2. Cherry-pick
    3. Branching strategies
        1. Git flow
        2. Github Flow
        3. Truck-Based Development

    4. Git Ignore
        - prevents commiting
            - Secrets
            - Dependencies
            - Build files
    
    5. How to resolve conflict
        1. Confilict occer during merge/rebase
        2. Open conflicting file
        3. Edit manually -> keep correct version
        4. Then 
            - git add .
            - git commit -m "message"
            For Rebase
            - git rebase --continue

    6. Hard vs Soft Reset
        - Soft Reset
            - git reset --soft Head~1
            - Undo commit
            - Keep chanes staged
        - Hard Reset
            - git reset --hard Head~1
            - delete commit and changes permantly
        - Use hard reset carefully (destuctive)

    7. Git Stash
        - Temporarily save uncommited changes
            - git stash
            - git stash pop
        - useful when switching branches mid-work

    8. Git Clone vs Fork
        - Clone
            - copy repo to your local machine
            - git clone <repo_url>
        - Fork
            - copy repo to a github account
            - user for contributing to others project

    9. Pull vs Fetch
        - Fetch
            - git fetch
            - download changes
            - doesent modify your working branch
        - Pull
            - git pull
            - fetch + merge
        Safer workflow
        - git fetch
        - git pull

    10. Reset vs Revert
        - Reset
            - Move branch  pointer (rewrite hostory)
            - local changes
        - Revert
            - git revert <commit>
            - create new commit that undo changes
            - safe for shared branches
            - shared history
